# Homelab Notes

IT support technician (4 years of experience with Android, iOS and Windows) transitioning into **server engineering, virtualization and cybersecurity**. This repository documents my learning path, lab setups and notes.

## Goals
- Build a hands-on homelab with Windows Server, Active Directory and RHEL-based Linux
- Pass certifications: AZ-900, RHCSA, Security+
- Move into a Junior SysAdmin / Infrastructure role

## Lab Environment
| Component | Details |
|-----------|---------|
| Host OS | Fedora (i3) |
| Hypervisor | KVM / libvirt (virt-manager) |
| VMs | Windows Server (Domain Controller), Windows client, Rocky Linux |
| Network | Isolated virtual network [192.168.100.0/24] |

## Repository Structure
```

02-rhel-linux/       Storage (LVM), firewalld, SELinux, services

```
